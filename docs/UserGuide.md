# SENAITE User Guide

A detailed, end-user oriented guide to SENAITE LIMS. Each chapter is a
self-contained document that explains one area of the system — what it is
for, how to use it step by step, how it behaves through the laboratory
workflow, and which setup options control it. Chapters cross-reference each
other where topics touch.

Read the chapters in order for a complete tour of the system, or jump
directly to the topic you need.

---
